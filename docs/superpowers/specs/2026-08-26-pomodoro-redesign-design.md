# 番茄钟交互重设计

## 目标

修复休息倒计时显示不稳定、日期没有真实数据、页面用途不清晰的问题，并让 240×280 屏幕上的番茄钟无需猜测即可操作。

## 交互设计

- 番茄钟页面默认展示标题“番茄时钟”、当前阶段“专注”或“休息”、单个固定宽度的 `MM:SS` 倒计时、阶段状态和进度条。
- 阶段按“专注 25 分钟 → 休息 5 分钟 → 专注 25 分钟”循环。专注完成后自动进入休息，休息完成后自动进入下一轮专注。
- 操作区固定为三个按钮：“开始/暂停”“跳过”“重置”。跳过直接进入下一阶段；重置停止计时并恢复当前阶段的默认时长。
- 大时钟模式保留为次级模式，显示当前时间和真实日期；底部模式按钮使用明确的“切换到大时钟”或“切换到番茄钟”文案。
- 日期通过现有 `date_str` 数据链路传给番茄钟，不再依赖初始化时的占位字符串；使用高对比度中文字体显示。

## 实现边界

- 只修改 `main/ui/ui_pomodoro.c/.h`、调用它的 `main/app/app_business.c`、Level 21 归档源码、教程和番茄钟静态回归检查。
- 不修改 TileView 四向页面、程序列表、SW3 导航或固定显示屏配置。
- 倒计时仍由现有业务任务每秒调用一次 UI tick；状态机只在番茄钟模式运行。

## 验收标准

1. 源码不再拆分显示分钟和秒，倒计时使用单一 `MM:SS` 标签并为分钟、秒补零。
2. 源码包含专注/休息两个阶段、跳过和重置行为，以及阶段完成后的自动切换。
3. 日期更新接口被业务层调用，页面不再只显示 `-- 年 -- 月 -- 日` 占位文本，且日期颜色不是低对比度颜色。
4. 静态回归检查通过，ESP-IDF v6.0.2 构建通过。

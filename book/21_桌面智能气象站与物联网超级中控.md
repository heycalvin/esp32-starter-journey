## 21.3 📱 ESP32 触控桌面与程序列表交互设计

为了避免 2048 等应用的内部手势和桌面切页手势互相抢事件，固件采用“快捷页 + 应用列表”两级交互：

```text
                         上滑：控制中心
                               ▲
左滑：番茄钟 / 大时钟  ◄── 首页看板 ──► 右滑：系统状态
                               ▼
                         下滑：传感器趋势

首页短按 SW3 → 程序列表 → 点击进入 2048 / 相册 / 小说
应用内短按 SW3 → 返回首页
长按 SW3 3 秒 → 保留为 Wi-Fi 配网重置
```

四个方向页只放高频、适合快速查看的设备功能：控制中心、传感器趋势、番茄钟和系统状态。电子相册、小说阅读器与 2048 属于需要连续触摸或沉浸操作的独立应用，统一从程序列表进入。

程序列表采用纵向整行布局：标题、应用名称和用途说明统一使用中文字库；图标只使用设备内置 Montserrat/FontAwesome 符号或数字徽标，不依赖 Emoji，避免在小屏上出现方块。列表中的每一行都可以直接点击打开对应应用，右上角“返回首页”用于退出程序列表。

应用运行时由独立全屏容器覆盖桌面 `TileView`，应用自己的触摸手势不会冒泡到外层页面；因此 2048 的上下左右滑动只负责移动方块，不会误切换到其他页面。

### ⏱️ 快捷页三：番茄时钟与大时钟
* **清晰阶段**：番茄钟页面明确显示“专注 · 25分钟”或“休息 · 5分钟”，专注完成后切换到休息，休息完成后进入下一轮专注；
* **稳定倒计时**：剩余时间由单个 `MM:SS` 标签显示，分钟和秒始终补零，不再拆成多个容易错位的文字块；
* **三个明确操作**：使用“开始/暂停”“跳过”“重置”控制当前阶段，进度条同步显示阶段进度；
* **大时钟模式**：可切换到独立的大时钟页面，显示 `HH:MM:SS` 和从 SNTP 时间链路更新的真实年月日。

### 🌤️ 首页：气象时钟看板 (Weather Station)
* **网络自动授时**：开机连接 Wi-Fi 后，SNTP 自动校准东八区毫秒级时间，生成 `HH:MM:SS` 数字大时钟；
* **动态拟物天气**：HTTP 轮询气象接口，动态展示天气状态（晴 ☀️ / 雨 🌧️ / 阴 ⛅）、实时气温与湿度；
* **轻量状态提示**：标题栏保留 Wi-Fi、SD 卡和剩余内存图标，快速反映设备状态；详细网络/IP 与存储信息在控制中心和系统状态页查看；
* **底部环境概览**：利用屏幕下方空间展示温度、湿度与环境舒适度，右侧照明卡片整体可点击，用于快捷控制板载 LED2，不额外展示距离。

### 🎛️ 快捷页一：智能传感器与 IoT 中控 (Sensor Hub)
* **多传感器动态仪表**：NTC 热敏高精度温度条、HC-SR04 超声波雷达测距条动态实时刷新；
* **板载交互**：触控屏幕大按钮，秒级点亮/熄灭板载 LED2，状态通过 MQTT 同步推送至手机与云端；
* **MQTT 遥测上报**：每 3 秒自动打包 JSON 报文向公共 Broker（`broker.emqx.io:1883`）发送遥测流。

### 🖼️ 程序列表应用一：TF 卡触控电子相册 (Photo Gallery)
* **文件流加载**：扫描 TF 卡 `/sdcard/photos/` 目录下的照片壁纸；
* **触控手势切图**：轻触屏幕下方 **Next Photo** 或左右滑动，秒级切换壁纸，尽显 1.69 寸 IPS 高清屏色彩！

### 📖 程序列表应用二：TF 卡电子小说阅读器 (Novel Reader)
* **长文本流式分页**：从 TF 卡 `/sdcard/novel.txt` 流式读取，按每页 160 字符优雅排版；
* **触控前后翻页**：屏幕左下角 **上一页 (Prev)**、右下角 **下一页 (Next)** 触控翻页，底部实时显示当前页码与总页数！

### ⚙️ 快捷页四：系统健康、无线中控与 OTA 升级 (System Center)
* **硬件健康监视**：实时显示剩余 Free Heap 内存（约 180 KB）与外部 PSRAM 空闲大小（约 1.8 MB）；
* **双模 OTA 状态机**：进入固件刷机状态时，全屏浮现 OTA 升级进度条，实时显示固件写入百分比；
* **看门狗与 Core Dump**：展示当前 6000ms 任务看门狗守护状态与 Flash Core Dump 故障黑匣子就绪标志。

### 🎮 程序列表应用三：2048 触控游戏
* **独立全屏游戏容器**：从程序列表点击进入，运行时不参与桌面横向切页；
* **四向手势隔离**：棋盘只接收自己的上下左右滑动，用于数字移动和合并；
* **SW3 返回首页**：短按板载 SW3 离开游戏，回到首页看板。

## 21.4 💻 PC 端 Web 智能管理平台 (Rust + Vue 3) 快速启动指南

### 1. 启动 Rust 高性能后端 (`backend_rust/`)
在终端进入目录并运行：
```bash
cd code/21_final_station_hub/server/backend_rust
cargo run
```
* **运行地址**：`http://localhost:8080`
* **核心接口**：
  * `POST /api/photo/process`：将任意尺寸图片自动智能居中裁剪缩放为 240×280 并推送到 ESP32；
  * `POST /api/novel/process`：将 TXT 小说按段落分卷切片并下发到 ESP32 TF 卡；
  * `POST /api/ota/upload`：上传 `esp32_journey.bin`，计算 SHA256 并通过 HTTP OTA 接口推送给 ESP32。

### 2. 启动 Vue 3 现代前端看板 (`frontend_vue3/`)
在终端进入目录并运行：
```bash
cd code/21_final_station_hub/server/frontend_vue3
npm install
npm run dev
```
* **访问地址**：浏览器打开 `http://localhost:3000` 即可尽情体验深色玻璃拟物大屏中控！

### 3. 打开免安装 Web-Bluetooth 网页版 (`web_bluetooth/`)
* 双击或在手机 Chrome/Edge 中打开 `code/21_final_station_hub/server/web_bluetooth/index.html`，无需安装任何 APK 即可直接通过浏览器直连 ESP32 蓝牙！
